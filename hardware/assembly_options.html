A · Full DIY $135–160

5 bare PCBs + every part bought retail; you solder all ~17 components per board. Recomputed with live prices — see below.

✓ no reflow/hot-air needed  Effort

You do

  • 20 big, easy THT joints per board for the 2 modules (XIAO + mic breakout) — no fine work at all
  • 5 Choc switches + fine-tip-iron work on the 1 SMD LED and 1 SMD latch switch
  • ~1–2 h/board, ~5–10 h total for 5 — down a lot from the old bare-mic-chip build

Where the money goes (live-quoted 2026-07-02)

  • PCB fab $2.00–$6.10/5 at JLCPCB (real instant quote — the 104mm length did not push this out of the cheap prototype tier the way the old estimate assumed)
  • Parts/board: XIAO $4.90 (Seeed direct) · mic breakout $6.95 (Adafruit direct) · 5 switches ~$4.40–5.35 (splitkb.com) · 5 caps ~$4.40–5.35 (splitkb.com) · latch switch $0.66–0.71 (SW6 candidate, see BOM) · LED+passives ~$1 (not re-quoted this pass)
  • 3+ supplier shipments ~$20–30 (not re-quoted this pass)

No special tools needed anymore — a fine-tip iron handles everything, including the SMD LED (gull-wing pads, not the old reflow-only mic chip).

B · Vendor solders the fiddly bits only $190–260

Vendor assembles the LED, latch switch, and passives (the small SMD/THT parts) via standard PCBA. You solder the 5 keyswitches and both modules yourself.

✓ beginner-level iron work  Effort

You do

  • ~30 THT joints/board: 5 switches + 20 module pins — all big, easy, no fine work
  • ~20–30 min/board

Vendor does

  • LED, latch switch, passives via standard SMD/THT line
  • Fees: setup+stencil ~$35–70, part-line loading ~$5–10 — not independently re-quoted this pass, carried over from the search-snippet round; the $70 drop from the old range is entirely the live-quoted PCB fab + parts correction from Option A

Worth it mainly if hand-soldering the small SMD LED/latch switch feels intimidating — otherwise Option A gets you most of the way for less.

Recommended

C · Vendor does everything except the 2 modules $210–280

The realistic "best vendor tier" ceiling: keyswitches, latch switch, LED, and passives all vendor-assembled. You solder only the XIAO and mic breakout — 20 big through-hole pins, no fine work whatsoever.

✓ easiest reliable tier  Effort

  • ~10–15 min/board: push 20 pins through, flip, solder
  • Doesn't depend on either vendor agreeing to place an irregular header-mounted module — the one part of this build that's genuinely uncertain is skipped entirely
  • Real anchor this pass: PCBWay's live Combo/Consigned calculator quoted $88 assembly-service cost for 5 boards (9 unique parts, 5 SMD, 8 THT) — a real number, though still a calculator estimate pending engineering review of the actual modules, not a firm quote

This is the sensible default: it doesn't gamble on an unconfirmed vendor capability, and the 20 joints it leaves you are the easiest ones in the whole design.

Partially confirmed — real fee floor, not fully speculative anymore

D · Full turnkey, zero solder $250–320

Two real paths now, not one hypothetical: JLCPCB's own Help Center documents an overseas parts-consignment process with a real fee schedule; PCBWay's Combo/Consigned flow is the same first-class option as before. Either could achieve genuine zero-solder if they accept the modules.

? module placement still unconfirmed  Effort

  • JLCPCB path, live-quoted 2026-07-02: $85 flat overseas-consignment service fee (1–50 part numbers — covers both modules for the same flat cost) + ~$0.22/part handling + $8 recommended baking fee + freight/customs to ship modules to China, borne by the customer. This is a documented, real fee — not a guess — but it's a meaningful fixed cost at 5-unit quantity that wasn't priced in before.
  • PCBWay path: Combo/Consigned calculator quotes $88 assembly service for 5 boards (same figure as Option C) — but this is a generic estimate, not confirmation they'll place the specific tall, header-standoff-mounted modules without an extra manual-placement surcharge once they review the real files.
  • Get a firm quote (real Gerbers + BOM/CPL, needs the board routed first — issue #13) before ordering either way; the range above already includes the real JLCPCB fee floor, so it's tighter than the old "wide because we don't know" range, but the ceiling is still an estimate.

E · Whole device, one vendor $235–340

Option C (the reliable tier) plus 5 sets of enclosure shells from JLC3DP or PCBWay's print service, in one combined order. STL/STEP files already in hardware/enclosure/output/.

✓ one order, easy self-assembly  Effort

  • Shell pairs est. $5–12 each in gray resin/PA12 (not re-quoted this pass)
  • Your entire build: solder 2 modules (10–15 min) + 4 screws + 5 keycaps per device
  • Swap in D's modules-included cost if that quote comes back reasonable

Sensible after the layout sign-off (issue #12) and one fit-check print — the enclosure grew to 22.6mm thick this revision, worth confirming in hand before ordering 5 sets.

  • Option D is no longer "speculative" in the sense of having zero real data — JLCPCB's $85 consignment fee is documented policy, and PCBWay's $88 Combo/Consigned figure is a live calculator output. Bottom line: pick C as the default — it doesn't gamble on unconfirmed vendor capability, and what it leaves you to solder (2 modules, 20 big pins) is genuinely the easiest part of the build. Get a firm PCBWay or JLCPCB quote for D with real Gerbers/BOM before ruling it out; upgrade to E once the enclosure fit-check print is done.
